# Nim - Webversion

Webversion des mathematischen Strategiespiels **Nim**, basierend auf der originalen iOS-App von [Heiko Etzold](https://github.com/heiko-etzold) und Günter Krauthausen.

**[Online spielen](https://www.lernsoftware-mathematik.de/nim)**

## Das Spiel

Nim ist ein kombinatorisches Strategiespiel, bei dem zwei Spieler abwechselnd Spielsteine aus mehreren Reihen nehmen. Wer den letzten Stein nimmt, gewinnt (oder verliert, je nach Spielvariante). Das Spiel eignet sich hervorragend zum Erforschen mathematischer Strategien im Unterricht.

## Features

- Konfigurierbares Spielfeld (Anzahl der Reihen und Steine)
- Spielvarianten: Wer den letzten Stein nimmt, gewinnt oder verliert
- Spielarchiv zum Speichern und Analysieren vergangener Partien
- Forschungsmodus zum Erkunden der Gewinnstrategie
- PDF-Export von Spielständen
- Vollständig offline nutzbar (kein Server erforderlich)
